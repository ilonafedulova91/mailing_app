# Сервис управления email-рассылками

Веб-приложение на Django для управления контактами, сообщениями и рассылками. Пользователь может задать период рассылки, запустить отправку писем и просмотреть результаты. В приложении также есть подтверждение электронной почты, личные данные пользователей и функции менеджера.

## Возможности

- Регистрация с подтверждением адреса электронной почты и вход в аккаунт.
- Создание и управление получателями, сообщениями и рассылками.
- Отправка писем только в заданный для рассылки период.
- Журнал успешных и неуспешных попыток отправки.
- Главная страница со статистикой по рассылкам и получателям.
- Функции менеджера: просмотр пользователей, получателей и рассылок, блокировка пользователей и отключение рассылок.
- Django Admin для администрирования данных.

## Требования

- Python 3.12 или новее.
- Poetry.

## Установка и запуск

Клонируйте репозиторий и перейдите в каталог проекта. Установите зависимости:

```bash
poetry install
```

Примените миграции и запустите сервер разработки:

```bash
poetry run python manage.py migrate
poetry run python manage.py runserver
```

Приложение будет доступно по адресу `http://127.0.0.1:8000/`, панель администратора — по адресу `http://127.0.0.1:8000/admin/`.

Чтобы создать учётную запись администратора, выполните:

```bash
poetry run python manage.py createsuperuser
```

### Настройка электронной почты

По умолчанию проект использует `django.core.mail.backends.console.EmailBackend`. Письма не отправляются на реальные адреса, а выводятся в терминал, где запущен сервер. Это удобно для локальной разработки: ссылку подтверждения регистрации можно открыть из вывода сервера.

Для отправки писем настройте почтовый backend Django и параметры SMTP в `config/settings.py` или через переменные окружения. Перед развёртыванием в рабочей среде замените настройки разработки и секретный ключ, хранящийся в исходном коде.

### Использование

1. Зарегистрируйтесь и подтвердите адрес по ссылке из письма.
2. Войдите в аккаунт.
3. Добавьте получателей и создайте сообщение с темой и текстом.
4. Создайте рассылку, выберите сообщение и получателей, задайте время начала и окончания.
5. В период активности откройте рассылку и запустите отправку. Результаты появятся в журнале попыток.

Каждый пользователь управляет собственными получателями, сообщениями и рассылками. Роль менеджера назначается в профиле пользователя через административную панель.

### Отправка рассылки из командной строки

Чтобы запустить рассылку по её числовому идентификатору, выполните:

```bash
poetry run python manage.py send_mailing <ID_РАССЫЛКИ>
```

Например:

```bash
poetry run python manage.py send_mailing 1
```

Перед отправкой команда проверяет, что рассылка включена и находится в пределах заданного периода.
